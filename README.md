# Better-Beta-Servers

Brings a proper server list to Minecraft Beta 1.7.3 multiplayer. No more typing IPs from memory every time.

## Features

- **Server list** — save servers with custom names, join with one click
- **Ping display** — live latency per server in green / yellow / red
- **Player count** — shows current / max players directly in the list
- **MOTD** — the server's message of the day shown inline
- **Favorites** — star any server to mark it
- **Edit / Remove** — full control over your saved servers
- **Direct Connect** — classic IP input, now with history
- **Direct Connect History** — last 10 addresses auto-saved and re-selectable
- **Copy IP** — copies any server address to clipboard instantly
- **Refresh** — re-ping all servers on demand

## Installation

### MultiMC / Prism Launcher
1. Right-click your Beta 1.7.3 instance and select **Edit Instance**
2. Go to the **jar mods** tab
3. Click **Add to Minecraft.jar** and select the downloaded `.zip`
4. Launch the game

### Manual
1. Locate your `minecraft.jar` (`.minecraft/bin/minecraft.jar`)
2. Open it with any archive tool (e.g. 7-Zip or WinRAR)
3. Delete the **META-INF** folder inside the jar
4. Drag and drop the mod files into the jar
5. Save and launch the game
